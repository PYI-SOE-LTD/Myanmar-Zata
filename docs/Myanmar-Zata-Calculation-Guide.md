# Myanmar Zata Calculation Guide
## ဇာတာ (Zata) တွက်နည်း / ဖွဲ့နည်း — Step‑by‑Step Explanation

ဤစာတမ်းသည်  
**မြန်မာ ဇာတာ (Zata / Janma Zata)** ကို  
နက္ခတ္တဗေဒ၊ ဝေဒအရ **မှန်ကန်စွာ တွက်ချက်ဖွဲ့စည်းနည်း** ကို  
သင်ကြားရေး / Practitioners အတွက် စနစ်တကျ ရှင်းလင်းထားခြင်း ဖြစ်သည်။

---

## 1. Zata (ဇာတာ) ဆိုသည်မှာ

**Zata** ဆိုသည်မှာ  
မွေးချိန်တစ်ချိန်တွင်  
ကောင်းကင်၌ရှိနေသော **ဂြိုဟ်များ၏ တည်နေရာတိတိ** ကို  
အခြေခံ၍ ဖွဲ့စည်းထားသော **ဘဝတစ်လျှောက်လုံး၏ Blueprint** ဖြစ်သည်။


> ဇာတာ = မွေးချိန် + မွေးနေရာ + Stellarium-level calculation

---

## 2. Zata တွက်ရန် မရှိမဖြစ်လိုအပ်သော Input များ

### 2.1 မွေးရက်စွဲ
- Year / Month / Day (Gregorian calendar)

### 2.2 မွေးချိန် (အရေးကြီးဆုံး)
- Hour : Minute (local time)
- မွေးချိန်မှားလျှင် → **ဇာတာလုံးဝမှား**

### 2.3 မွေးနေရာ
- မြို့ / ရွာ
- Latitude / Longitude

### 2.4 Time Zone
- Myanmar → UTC +6:30
- DST မရှိ

---

## 3. Astronomical Calculation (ကြယ်ဗေဒအဆင့်)

ဤအဆင့်သည် **တွက်ချက်ရာတွင် မျက်မှောက်ခေတ် Astronomy ကို အသုံးပြုရသော အဆင့်** ဖြစ်သည်။

### 3.1 Zodiac System ရွေးချယ်ခြင်း
- **Sidereal Zodiac (Lahiri Ayanamsa)** ကို သုံး
- Western Tropical မသုံး

### 3.2 Planetary Positions တွက်ခြင်း
အောက်ပါ ဂြိုဟ် ၉ လုံး၏ —
- ရာသီ (Sign)
- ဒီဂရီ (Degree)

ကို မွေးချိန်အတိအကျအရ တွက်ထုတ်ရသည်။

**ဂြိုဟ် ၉ လုံး**
- Sun (နေ)
- Moon (လ)
- Mars (ဂါ)
- Mercury (ဟူး)
- Jupiter (ကြာ)
- Venus (သော)
- Saturn (စနေ)
- Rahu
- Ketu

> Rahu / Ketu သည် Moon’s node ဖြစ်ပြီး  
> အမြဲတမ်း ၁၈၀° ဆန့်ကျင်နေသည်

---

## 4. Lagna (လဂ် / Ascendant) တွက်နည်း

### 4.1 Lagna ဆိုသည်မှာ
မွေးချိန်အခိုက်အတန့်တွင်  
**အရှေ့ဖက် မိုးကုတ်စက်ဝိုင်းပေါ် တက်လာသော ရာသီ** ဖြစ်သည်။

➡️ Lagna = ဇာတာ၏ အခြေခံအုတ်မြစ်

### 4.2 Lagna တွက်ရာတွင် ပါဝင်သည့်အချက်များ
- Birth time (UTC-adjusted)
- Latitude / Longitude
- Sidereal calculation

⚠️ မွေးချိန် ၄ မိနစ်လောက်ကွာရင်တောင်  
Lagna ပြောင်းနိုင်သည်

---

## 5. Bhava (ဘာဝ ၁၂ ပါး) ဖွဲ့စည်းနည်း

### 5.1 House System
- **Whole Sign House System** (Indian / Myanmar method)

### 5.2 Bhava Mapping Rule
- Lagna ရာသီ = **1st Bhava**
- ထိုနောက် sign ၁၂ ခုအတိုင်း ဆက်သွား

ဥပမာ —
- Lagna = Virgo  
→
1st = Virgo  
2nd = Libra  
3rd = Scorpio … စသည်

---

## 6. Zata Chart Layout (ဇာတာခွင် ပုံစံ)

### 6.1 Myanmar Zata Style
- South Indian–style square chart
- House positions တည်ငြိမ်
- ဂြိုဟ်များကို အိမ်ထဲထည့်

### 6.2 Chart ထဲတွင်ရေးသွင်းရသော အချက်များ
- Lagna sign
- ဂြိုဟ် ၉ လုံး၏ sign + degree
- Rahu / Ketu axis
- Moon Nakshatra

---

## 7. Nakshatra Calculation (နက္ခတ္တ ၂၇)

### 7.1 Moon Nakshatra
- Moon ရောက်ရှိနေသည့် 13°20′ အပိုင်း
- Nakshatra + Pada (1–4) သတ်မှတ်

### 7.2 Nakshatra ၏ အသုံး
- Dasha စတင်ဂြိုဟ်
- Psychological nature
- Timing logic

---

## 8. Vimshottari Dasha Calculation

### 8.1 Dasha System
- Vimshottari (120 years)

### 8.2 Starting Dasha
- Moon Nakshatra လိုက်၍ စ

### 8.3 Dasha Structure
- Maha Dasha
- Antar Dasha
- Pratyantar (လိုလျှင်)

➡️ Event timing တွက်ရန် **အဓိကသော့ချက်**
